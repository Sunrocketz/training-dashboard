# Глоссарий

| Термин | Значение |
|--------|----------|
| Группа | Строка обучения на листе-источнике с датой старта |
| Valid-группа | Группа, попавшая в расчёт конверсий (не «не собралась» / «распалась») |
| Воронка | Цепочка day1 → day2 → day3 → выход на линию |
| Конв. 1→5 | Доля итогового выхода относительно 1-го дня (см. нюансы в ApiContract) |
| `/exec` | URL развёрнутого Web App Apps Script |
| clasp | CLI для синхронизации Apps Script с локальными файлами |
| ADR | Architecture Decision Record (`Decisions.md`) |
| SoT | Source of Truth — источник истины для данных/контракта |
