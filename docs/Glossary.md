# Глоссарий

| Термин | Значение |
|--------|----------|
| Группа | Строка обучения на листе-источнике с датой старта |
| Valid-группа | Группа в учёте стартов: есть дата старта и комментарий не «не собралась» (в т.ч. «распалась» с меткой) |
| Законченная группа | Valid и (`lineDate` ≤ сегодня или «распалась») — участвует в воронке, выходе, конверсиях, TQI |
| Группа в обучении | Valid, D ещё в будущем, не «распалась» — только в счётчике стартов (`groups`) |
| Распавшаяся группа | Valid-группа с `fellApart: true` (комментарий содержит «распалась») — учитывается в KPI и воронке |
| Не собралась | Вне valid; только счётчик `notGathered` |
| TQI v3 / `score` | Воронка 40% + балл после линии 5% + оценка кандидатов 5% + вклад/надёжность/yield/стабильность (ADR-016) |
| Оценка кандидатов | Среднее «да» по скрипту, возражениям и CRM из журнала ОС (`scoreParts.skills`); колонка рейтинга, 5% TQI |
| Уволенные / `excludedTrainers` | Нет в рейтинге и оценке линии; группы остаются в воронке компании (ADR-018) |
| Оценка после линии / `lineReview` | Средняя подготовка 1–5 и доли «да» (скрипт/возражения/CRM) из журнала ОС; балл и оценка кандидатов входят в TQI v3 (ADR-015/016) |
| Вклад (`contributionShare`) | Доля итоговых выходов тренера от всех выходов компании, % |
| Выход/группу | `finalCount / groupsCompleted` — продуктивность законченного потока |
| Воронка | Цепочка day1 → day2 → day3 → выход на линию |
| Конв. 1→5 | Доля итогового выхода относительно 1-го дня (см. нюансы в ApiContract) |
| `/exec` | URL развёрнутого Web App Apps Script |
| clasp | CLI для синхронизации Apps Script с локальными файлами |
| ADR | Architecture Decision Record (`Decisions.md`) |
| SoT | Source of Truth — источник истины для данных/контракта |
